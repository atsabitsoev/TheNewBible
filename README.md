# Библия — читалка для iOS (MVP)

Простая читалка Библии на SwiftUI в стиле iOS 26 (Liquid Glass).

## Что умеет

- **Три перевода:** Синодальный, перевод еп. Кассиана (только Новый Завет) и Новый русский перевод (НРП). Перевод переключается кнопкой в правом верхнем углу, место чтения при этом сохраняется.
- **Отрывки.** Текст разбит на отрывки с заголовками. Нажатие на заголовок открывает экран «Об отрывке»: толкования на весь отрывок и его текст в любом из трёх переводов.
- **Стихи.** Нажатие на стих открывает экран «О стихе» с тремя вкладками:
  - **Слова** — греческий (Тишендорф) или еврейский (Ленинградский кодекс) текст стиха с номерами Стронга. Для каждого слова показаны транслитерация и краткое значение, по нажатию открывается полная статья словаря. Ссылки на другие номера внутри статьи тоже работают.
  - **Толкования** — святые отцы и библеисты с «Азбуки веры». Библейские ссылки внутри толкований открываются для просмотра, а место чтения остаётся на месте.
  - **Переводы** — стих во всех трёх переводах.
- **Другое место без потери своего.** Если открыть другое место (через выбор книги, ссылку «Ин 3:16» в поиске или ссылку из толкования), текущая позиция запоминается. Внизу появляется стеклянная кнопка «Вернуться к Ин 3:16», долгое нажатие на неё показывает историю мест. Ссылку из толкования можно сначала просто посмотреть и только потом нажать «Перейти сюда».
- Позиция, перевод и история сохраняются между запусками. Прочитанные главы, статьи и толкования кэшируются и открываются без интернета.
- Настраиваются размер шрифта и шрифт с засечками.

## Сборка

Нужны Xcode 26 и iOS 26.

1. Откройте `TheNewBible.xcodeproj`.
2. В настройках таргета *TheNewBible → Signing & Capabilities* выберите свою команду (Team). При необходимости поменяйте Bundle Identifier (`com.thenewbible.reader`).
3. Запустите на симуляторе или устройстве.

Проект использует синхронизируемые папки Xcode: всё, что лежит в `TheNewBible/`, попадает в сборку автоматически. Для [XcodeGen](https://github.com/yonaskolb/XcodeGen) есть альтернативное описание `project.yml`.

### Тесты ядра

Модели, разбор источников и навигация по ссылкам не зависят от UI и собраны в Swift-пакет `BibleCore` (`Package.swift`). Тесты запускаются так:

```sh
swift test
```

Работает на macOS и Linux.

## Устройство проекта

```
TheNewBible/
  App/            точка входа
  Core/           модели, разбор источников, загрузка и кэш (без SwiftUI)
  State/          AppModel, ReaderState (позиция, история «вернуться»)
  Views/
    Reader/       экран чтения, строки стихов, заголовки отрывков, кнопка «Вернуться»
    Details/      «О стихе», «Об отрывке», Стронг, толкования, просмотр другого места
    Navigation/   выбор книги и главы, настройки
    Components/   общие компоненты (RichText, FlowLayout, состояния загрузки)
  Resources/      pericopes.tsv (отрывки), versecounts.tsv (число стихов в главах)
Tests/BibleCoreTests/  тесты ядра
Tools/            скрипты, которыми собраны файлы из Resources
```

## Источники данных

Тексты переводов и толкования в репозиторий не входят. Приложение загружает их во время работы:

| Что | Откуда |
|---|---|
| Синодальный перевод, НРП | [bolls.life](https://bolls.life) |
| Греческий текст (Tischendorf 8th ed.) и еврейский (WLC) с номерами Стронга | bolls.life |
| Словарь Стронга («Полный лексикон по Стронгу и Дворецкому») | bolls.life |
| Перевод еп. Кассиана | [azbyka.ru/biblia](https://azbyka.ru/biblia/) |
| Толкования | azbyka.ru/biblia |

Все тексты принадлежат своим правообладателям. НРП (© Biblica) и перевод еп. Кассиана защищены авторским правом. Перед публикацией приложения в App Store нужно получить разрешения правообладателей и согласовать использование API с владельцами сайтов.

В репозиторий входят только собственные данные проекта:

- `Resources/pericopes.tsv` — деление на отрывки (3093 заголовка). Границы взяты из заголовков Berean Standard Bible (передана в общественное достояние в 2023 г.), переведены на русский и пересчитаны на синодальную нумерацию стихов. Пересобрать: `python3 Tools/build_pericopes.py`. Таблица переводов заголовков лежит в `Tools/pericope_titles_ru.tsv`.
- `Resources/versecounts.tsv` — число стихов в каждой главе по Синодальному переводу. Пересобрать: `python3 Tools/build_verse_counts.py`.

## Ограничения MVP

- Нумерация стихов в переводах и в оригинале иногда расходится. Псалмы, Иоиль, Малахия, Даниил 3 и Рим 14/16 пересчитываются автоматически. В остальных местах на вкладке «Слова» можно вручную сдвинуть стих в оригинале на один вперёд или назад.
- Неканонических книг Синодального перевода пока нет.
- Нет закладок, заметок, поиска по тексту и аудио: это сознательно оставлено за рамками MVP.
